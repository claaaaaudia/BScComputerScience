# 🎓 Computer Science Bachelor Projects — University of Minho

This repository is a collection of projects and lab assignments developed throughout my Bachelor’s degree in Computer Science at the University of Minho. Each project contributed to building a strong theoretical foundation alongside practical development experience.

Each folder contains the corresponding source code and reports for specific courses. Below is an overview of the projects, along with their main goals and the skills acquired.

---

## 🧩 Algorithmics Lab

First ever university project! A **terminal-based dungeon crawler** built using `ncurses`.

You play as a former cook on a revenge quest against the villainous **Chef Passadini**. The game features procedurally generated levels where you:

* Explore maps with 8-directional movement
* Fight enemies using directional and area attacks
* Avoid traps and collect stat-boosting items
* Progress through increasingly difficult floors

🎯 **Goal:** Clear all 15 levels and defeat the final boss.

**Key Features:**

* Procedural map generation
* Progressive difficulty scaling
* Character upgrades (vision, damage, health, etc.)

**Skills acquired:**
`Imperative Programming` · `Data Structures`

## 🧮 Algebra of Programming

A project focused on **formal and algebraic approaches** to program construction using Haskell.

Emphasis is placed on:

* Compositional design
* Higher-order combinators
* Literate programming

**Main Problems:**

* 🗳️ Implementation of the **D’Hondt method** for seat allocation
* 🔀 Generalization of merge sort via **hilomorphisms**
* 🔢 Efficient computation of **Catalan numbers**
* 📊 Solving the **largest rectangle in a histogram** problem

**Skills acquired:**
`Recursion Schemes` · `Algorithm Optimization` · `Mathematical Reasoning`

## ⚔️ Concurrent Programming

A multiplayer dueling game: **Duelo**

**Gameplay:**

* 2-player real-time combat
* Projectile shooting with modifiers
* Score-based winner system (2-minute matches)

**Architecture:**

* 🖥️ Client: Java (graphics & input)
* ⚙️ Server: Erlang (logic, physics, matchmaking)

**Additional Features:**

* Player ranking (Top 10)
* Level progression system
* Persistent account storage

**Skills acquired:**
`Concurrent Programming (Erlang)` · `Client-Server Architecture` · `Networking (TCP)`
