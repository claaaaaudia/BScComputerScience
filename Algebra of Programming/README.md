## 🧮 Algebra of Programming

This project focuses on applying formal and algebraic methods to program construction using Haskell. The work emphasizes compositional programming with higher-order combinators, encouraging concise, elegant solutions supported by clear documentation in a literate programming style.

The assignment is divided into four main problems:

- implementing the Hondt method for seat allocation and analyzing wasted votes;
- generalizing merge sort to handle multiple lists via hilomorphisms;
- optimizing the computation of Catalan numbers using mutual recursion to avoid factorial overhead;
- and solving the “largest rectangle in a histogram” problem using structured recursion patterns.

🎯 Skills acquired: recursion schemes, algorithm efficiency, and mathematical reasoning in program design.
